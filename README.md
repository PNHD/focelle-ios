# Focelle

Focelle is an iPhone-first AI photo coach built with SwiftUI, AVFoundation, Vision, Core Image, StoreKit 2, and a Cloudflare/Gemini backend.

The beta includes native camera controls, owned filters and custom presets, existing-photo editing, on-device composition guidance, optional cloud AI plans, privacy controls, remote beta/quota handling, and production-disabled commerce/referral paths.

Product scope and release requirements live in [`docs/focelle-spec.md`](docs/focelle-spec.md), [`docs/focelle-plan.md`](docs/focelle-plan.md), and [`docs/testflight-checklist.md`](docs/testflight-checklist.md).
